# DANZUS

DANZUS is the product hub for applied AI software and implementation work from Dan Johnson.

The site connects three pieces of the public story:

- DimeVision: AI-assisted weld inspection and student training workflows
- Agent Audit Trail: governance infrastructure for agentic AI workflows
- AI implementation services: practical systems that turn messy customer workflows into usable, governed software

## Employer Signal

This repo is useful as company and product context rather than as the main code sample. It shows positioning, product packaging, SEO/GEO work, and how the public portfolio ties together around AI implementation, compliance, and applied workflow software.
